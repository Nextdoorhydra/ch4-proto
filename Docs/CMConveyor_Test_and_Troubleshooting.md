# Chimera 컨베이어 테스트 및 문제 해결

> 컨베이어 사용법은 `CMConveyor_User_Guide.md`를 참고한다. 이 문서는 기능 검증과 이상 동작 확인 시에만 사용한다.

## 1. 기능 테스트 체크리스트

### 기본 이동

- [ ] 직선 컨베이어에서 파츠가 정방향으로 이동한다.
- [ ] 곡선 컨베이어에서 파츠가 경로를 따라 자연스럽게 회전한다.
- [ ] 배치한 파츠의 초기 위치 오프셋과 회전이 유지된다.
- [ ] 플레이어가 파츠를 획득하면 컨베이어 이동이 중지된다.
- [ ] 열린 일반 컨베이어 종단에서 파츠가 제거된다.

### 자동 연결

- [ ] 루트 컨트롤러의 `First Segment`만 지정해도 연결된 세그먼트가 동작한다.
- [ ] 분배기 이후 양쪽 출력 경로가 자동으로 동작한다.
- [ ] 물리적으로 끊어진 다른 컨베이어는 같은 네트워크로 인식되지 않는다.
- [ ] 수동 출력 컨트롤러 없이 파츠 인계가 이어진다.

### 방향 변경

- [ ] `SetConveyorDirection(Forward)`가 전체 네트워크에 적용된다.
- [ ] `SetConveyorDirection(Reverse)`가 전체 네트워크에 적용된다.
- [ ] `ReverseConveyorDirection()`을 연속 호출해도 정상 반전된다.
- [ ] 방향 반전 후 분배기도 같은 방향으로 움직인다.

### 분배기

- [ ] `Straight`에서 파츠가 같은 레인으로 나온다.
- [ ] `Cross`에서 파츠가 반대 레인으로 나온다.
- [ ] 정방향과 역방향 모두에서 Straight/Cross가 동작한다.
- [ ] 분배기에서 다음 컨베이어로 파츠가 인계된다.
- [ ] 좌우 메시 교체 후 외형과 경로가 정상이다.

### 순환 경로

- [ ] `Closed Loop` 활성화 시 파츠가 제거되지 않고 순환한다.
- [ ] 여러 번 순환해도 시작·끝 연결부에서 파츠가 멈추지 않는다.

## 2. 문제 해결

### 스플라인이 보이지 않는다

1. 뷰포트의 `Show → Advanced → Splines`를 활성화한다.
2. 컨트롤러가 아니라 직선·곡선 세그먼트 또는 분배기를 선택한다.
3. 실제 이동 스플라인은 각 컨베이어 BP가 소유한다.

### 컨트롤러를 옮겨도 경로가 따라오지 않는다

정상 동작이다. 컨트롤러 위치는 이동 경로와 관계없다. 컨트롤러는 `First Segment`부터 각 컨베이어 BP가 가진 경로를 사용한다.

### 파츠가 움직이지 않는다

1. 루트 컨트롤러의 `First Segment`가 지정되어 있는지 확인한다.
2. 파츠가 컨베이어 감지 영역 안에 있는지 확인한다.
3. 파츠가 `ACMPartActorBase` 계열인지 확인한다.
4. 파츠가 다른 액터에 Attach되어 있지 않은지 확인한다.
5. `Move Speed`가 0보다 큰지 확인한다.

### 연결부에서 파츠가 멈춘다

1. 앞 컨베이어의 빨간색 끝 화살표와 다음 컨베이어의 초록색 시작 화살표가 맞는지 확인한다.
2. 두 화살표의 진행 방향이 일치하는지 확인한다.
3. 분배기 입력·출력과 컨베이어 시작·끝이 같은 레인에 놓였는지 확인한다.
4. 같은 네트워크에 루트 컨트롤러가 중복 배치되지 않았는지 확인한다.
5. 특수 배치라면 컨트롤러의 연결 허용 거리 설정을 확인한다.

### 분배기 출력에서 파츠가 대기한다

분배기는 다음 컨베이어가 파츠를 받을 때까지 출력 끝에서 인계를 재시도한다.

1. 출력 컨베이어가 분배기 경로와 연결되어 있는지 확인한다.
2. 출력 컨베이어의 시작 화살표 방향을 확인한다.
3. 해당 출력 컨베이어가 자동 검색된 네트워크에 포함되는지 확인한다.
4. 분배기와 출력 컨베이어 사이에 불필요한 별도 컨트롤러가 없는지 확인한다.

### 플레이하면 파츠 위치나 회전이 바뀐다

1. 컨트롤러와 분배기의 `Preserve Initial Part Placement`가 활성화되어 있는지 확인한다.
2. 파츠 원점이 감지 영역 안에 있는지 확인한다.
3. 파츠가 다른 액터에 Attach되어 있지 않은지 확인한다.

### 방향 변경이 일부 구간에만 적용된다

1. 개별 분배기가 아니라 루트 `BP_CMConveyorRouteController`에 방향 함수를 호출한다.
2. 플레이 도중 컨베이어를 새로 생성하지 않았는지 확인한다.
3. 적용되지 않은 구간이 물리적으로 끊어진 별도 네트워크인지 확인한다.
4. 외부 트리거가 서버에서 함수를 호출하는지 확인한다.

### Cross 설정이 현재 파츠에 적용되지 않는다

파츠가 분배기 중앙을 지난 뒤 모드를 변경하면 해당 파츠에는 적용되지 않는다. 다음 테스트에서는 파츠가 중앙에 도달하기 전에 `SetRoutingMode(Cross)`를 호출한다.

## 3. 배치 검증 체크리스트

- [ ] 시작·끝 화살표 위치와 방향이 맞다.
- [ ] 분배기의 양쪽 입력과 출력이 올바른 레인에 연결되어 있다.
- [ ] 연결된 네트워크당 루트 컨트롤러가 하나다.
- [ ] 컨트롤러의 `First Segment`가 지정되어 있다.
- [ ] 분배기와 컨베이어의 이동 속도가 의도대로 설정되어 있다.
- [ ] 순환 경로에만 `Closed Loop`가 활성화되어 있다.
- [ ] 파츠가 감지 범위 안에 있고 Attach되어 있지 않다.
- [ ] 외부 트리거가 서버에서 방향·분배 함수를 호출한다.
